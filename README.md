## 📑 Lab Topics & Tasks Breakdown

### 🔬 Observations
| Task | Description | Technologies |
| :--- | :--- | :--- |
| **Task 1** | College Information Portal (ANITS), Student Registration Form, Tables, Multimedia | HTML5 |
| **Task 2** | Responsive Styled Webpage, HTML5 Canvas Graphics, Flexbox Cards | HTML5, CSS3, Canvas API |
| **Task 3** | Student Profile Generator with ES6 Classes and Dynamic DOM creation | HTML5, CSS3, JavaScript (ES6) |
| **Task 4** | Interactive Todo List with Add, Toggle Complete, and Delete functionality | HTML5, CSS3, JavaScript |
| **Task 5** | Product Calculator Events, Node.js File System I/O, Express REST API, DOM Demo | HTML5, JavaScript, Node.js, Express.js |
| **Task 6** | Functions vs Classes, Node.js Built-in Core Modules (os, path, fs), NPM, Express Middleware | JavaScript (ES6), Node.js, Express.js |

### 📖 Lab Records & Practice
| Week / Experiment | Topic / Program | Key Concepts |
| :--- | :--- | :--- |
| **Week 1 / Exp 1** | Static Webpage & Registration | Tables, Forms, Text Formatting, Lists, Hyperlinks |
| **Week 2 / Exp 2** | Webpage Styling | Gradients, Flexbox, Navigation Bar, Hover Transitions |
| **Week 3 / Exp 3** | JavaScript Basics & OOP | Arrays, Functions, Calculations, ES6 Classes, Object Manipulation |
| **Week 4 / Exp 4** | Dynamic Web Application | Live Digital Clock (`setInterval`), DOM Events, Dynamic Theme Switching |

### 📝 Assignments
| Assignment | Topic | Key Concepts |
| :--- | :--- | :--- |
| **Assignment 1** | `inheritencetypes` | Single, Multilevel, and Hierarchical Inheritance in JavaScript (ES6 `class`, `extends`, `new`) |
